# Universal Git Infrastructure (UGI)

Independent local-first Git workbench. Python local service + Persian RTL PWA; does not require the SOVEREIGN OS Android app.

The source package staged for this repository is UGI 1.1.0-alpha.4. Its local verification on 2026-11-02 produced 26 passing automated tests, a successful Python compile check and successful JavaScript syntax checks. Android JGit integration is deliberately outside this component.

Publication of the complete UGI source archive and remote checksum verification are the remaining steps for this component. The source license is MIT; the package retains its LICENSE file.
